# 📊 Painel de Soluções Corporativas - Exercícios em JavaScript

Dashboard funcional desenvolvido em **HTML5**, **CSS3** e **JavaScript (ES6)** para revisão acadêmica da disciplina de Desenvolvimento em JavaScript na **Faculdade Anhanguera (Unidade Osasco)**, sob orientação do prof. Marcel Teixeira.

---

## 🚀 Funcionalidades

* 💵 **Câmbio Comercial:** Conversão de valores de Reais (R$) para Dólares (US$).
* 🏷️ **PDV - Aplicar Desconto:** Cálculo do valor final com aplicação dinâmica de cupons (0%, 5%, 10% e 20%).
* 📈 **Simulador de Investimento:** Cálculo de rendimento mensal sobre o capital inicial.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do dashboard e formulários.
* **CSS3:** Estilização visual em cards organizados.
* **JavaScript:** Manipulação do DOM, funções dinâmicas e eventos de clique.
